### 3.1 `GET /grids` 🔓 — FN-01-01 ✅

**역할:** viewport 격자 목록  
**파일:** `grid.routes.ts` → `getGrids` / `gridUtils.bboxToRowColRange`

**Postman 입력**
```
GET http://localhost:4100/grids?sw_lat=37.56&sw_lng=126.97&ne_lat=37.58&ne_lng=126.99
```

**Postman 출력 (예시)**
```json
{
  "success": true,
  "data": [
    {
      "grid_id": 1,
      "lat": 37.566535,
      "lng": 126.977969,
      "infra_count": 12,
      "safety_grade": "안전"
    }
  ]
}
```

---

### 3.2 `GET /grids/{id}/infrastructures` 🔓 — FN-01-01 ✅

**역할:** 선택 격자 안 인프라 마커 (경찰서·소방서·CCTV·편의점)  
**Query:** `type` 선택 (`CCTV` \| `경찰서` \| `소방서` \| `편의점`)  
**파일:** `grid.routes.ts` → `getInfrastructures`

**Postman 입력**
```
GET http://localhost:4100/grids/112/infrastructures?type=CCTV
```
격자 클릭 후 경찰서·소방서 마커 예:
```
GET http://localhost:4100/grids/1/infrastructures?type=경찰서
GET http://localhost:4100/grids/1/infrastructures?type=소방서
```

**Postman 출력 (예시)**
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "type": "CCTV",
      "address": "서울특별시 …",
      "lat": 37.5665,
      "lng": 126.9779
    }
  ]
}
```

### 3.4 제보 — FN-02 ✅ (이미지 제외)

**파일:** `report.routes.ts`, `report.controller.ts`  
JWT는 컨트롤러 내 검증 (`Authorization: Bearer …`). login의 `sub` = user id.

| Method | Path | 인증 |
| :--- | :--- | :---: |
| GET | `/reports` | 🔓 |
| POST | `/reports` | 🔐 |
| PATCH | `/reports/{id}` | 🔐 본인 |
| DELETE | `/reports/{id}` | 🔐 본인/ADMIN |

#### GET `/reports`

**입력**
```
GET http://localhost:4100/reports?sw_lat=37.56&sw_lng=126.97&ne_lat=37.58&ne_lng=126.99
```

**출력 (예시)**
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "type": "공사",
      "lat": 37.5665,
      "lng": 126.978,
      "description": "…",
      "img_url": null,
      "user_nickname": "테스트유저",
      "created_at": "…",
      "expire_at": "…",
      "is_admin_posted": false
    }
  ]
}
```

#### POST `/reports`

**입력**
```
POST http://localhost:4100/reports
Authorization: Bearer {access_token}
Content-Type: application/json
```
```json
{
  "type": "공사",
  "lat": 37.5665,
  "lng": 126.978,
  "description": "도로 공사 중입니다."
}
```

**출력 (예시) 201**
```json
{
  "success": true,
  "data": {
    "id": 1,
    "grid_id": 123,
    "img_url": null,
    "expire_at": "…"
  }
}
```

#### PATCH `/reports/{id}`

**입력**
```
PATCH http://localhost:4100/reports/1
Authorization: Bearer {access_token}
Content-Type: application/json
```
```json
{
  "description": "공사 연장되었습니다."
}
```

**출력:** `{ "success": true, "data": { …수정된 제보… } }` (코드 기준)

#### DELETE `/reports/{id}`

**입력**
```
DELETE http://localhost:4100/reports/1
Authorization: Bearer {access_token}
```

**출력:** soft delete (`is_active=N`) 후 success 응답 (코드 기준)

### 3.5 인증 ✅

**파일:** `auth.routes.ts` → `register`, `login` / `auth.controller.ts`  
**명세:** `/auth/signup` → **구현 Path는 `/auth/register`**  
**테스트 계정 예:** `test@example.com` / `plainPassword123!` / 닉네임 `테스트유저`

#### POST `/auth/register`

**입력**
```
POST http://localhost:4100/auth/register
Content-Type: application/json
```
```json
{
  "email": "test@example.com",
  "password": "plainPassword123!",
  "nickname": "테스트유저"
}
```

**출력 201 (코드 기준)**
```json
{
  "success": true,
  "data": {
    "id": 6,
    "email": "test@example.com",
    "nickname": "테스트유저",
    "role": "NORMAL"
  }
}
```
- 409: 이메일 중복  
- 422: 필드 누락·비밀번호 8자 미만 등

#### POST `/auth/login`

**입력**
```
POST http://localhost:4100/auth/login
Content-Type: application/json
```
```json
{
  "email": "test@example.com",
  "password": "plainPassword123!"
}
```

**출력 200 (코드 기준)**
```json
{
  "success": true,
  "data": {
    "access_token": "eyJhbGciOiJIUzI1NiIs…",
    "user": {
      "id": 6,
      "nickname": "테스트유저",
      "role": "NORMAL"
    }
  }
}
```
- 401: 이메일/비밀번호 불일치  
- 403: `is_active=N`

> `refresh` / `logout` — 미구현(명세 없음). 필요 시 추가.

## 4. 앞으로 할 부분

우선순위: **웹 FE 지도** → (후속) city-events·관리자 정합 · auth refresh/logout(선택)

### 4.1 웹(FE) 카카오맵 연동 ❌ — FE 착수 대기

| 단계 | API |
| :--- | :--- |
| 지도 표시 | FE |
| bounds → 격자 | `GET /grids` |
| 격자 선택 → 마커 | `GET /grids/{id}/infrastructures?type=` |
| 인포카드 | `GET /grids/{id}/detail` |
| 도시정보 | `GET /city-events` (관리자 연동 후 고도화) |
| 제보 마커 | `GET /reports` |
| 로그인 | `POST /auth/register`, `/auth/login` |

피난처 UX가 「격자 안 경찰서·소방서」면 **`/shelters` 불필요** → infrastructures 사용.

### 4.2 `GET /shelters` ❌ 보류

- 격자 클릭 마커와 `GET /grids/{id}/infrastructures` 중복  
- 반경 검색 UX가 확정되면 재개

### 4.3 `GET /city-events` 후속

- 1차 bbox 조회는 완료  
- 관리자 등록/목록과 type·날짜·응답 필드 맞추기
